# Al-Quran App

A modern and responsive Al-Quran web application built using React and Vite.  
This project is designed to provide a clean reading experience with fast performance and a scalable frontend architecture.

---

## Live Demo

https://al-quran-wine.vercel.app/

---

## Features

- Clean and responsive Quran interface
- Fast performance powered by Vite
- Modern UI using Tailwind CSS & Flowbite
- Client-side routing with React Router
- Reusable component structure
- Mobile-friendly layout
- Organized and scalable project architecture

---

## Tech Stack

### Frontend

- React 19
- Vite
- Tailwind CSS v4
- Flowbite
- Flowbite React
- React Router DOM
- React Icons

## Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/username/alquran-app.git
```

### 2. Navigate to Project Folder

```bash
cd alquran-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

Application will run on:

```txt
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
